# HiperColor

HiperColor is an endless runner video game developed by JdDev for Windows.

Players control a sphere that must dodge obstacles, manage their health, and collect resources to unlock upgrades and cosmetic items.

## Project Status

Discontinued

Development of HiperColor has been discontinued. I am currently working on a new game with a similar concept, but it is an independent project and not an update to HiperColor.

## Features

- Obstacle Avoidance: Dodge obstacles that reduce the player's health upon collision.
- Visual Health System: Object colors indicate their associated danger level. Colors closer to red represent lower health.
- Dynamic Speed: Game speed changes throughout each run, increasing the challenge.
- Resource Collection: Collect coins and gems to unlock upgrades and cosmetic items.
- Customization: Unlock powers and skins to personalize the gameplay experience.

## Controls

- A/D: Move the sphere
- Mouse: Interact with the interface elements
